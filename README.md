# 萌宠变异录 MVP

基于 Cocos Creator **3.8.8** 的无素材塔防原型。宠物、敌人、道路和摇篮树均由 Graphics 绘制。

**当前仅支持竖屏。** 设计分辨率 720×1280；横屏或正方形窗口显示“请竖屏游玩”，战斗暂停。手机请竖持，桌面请使用竖向窗口。

## 运行

### 在 Cocos 中预览

1. 使用 Cocos Creator 3.8.8 打开本项目，等待脚本与资源导入。
2. 打开 `assets/Boot.scene`，Canvas 已挂载 `MvpGame`。
3. 点击编辑器的场景预览，选择竖屏手机设备或竖向的 Webpage Full Screen；横向窗口不能开始游玩。

### 运行独立 Web 版本

```sh
npm ci
npm run build:mvp
npm run serve
```

随后打开 [本地游戏](http://127.0.0.1:8090/)。构建默认使用本机 `/Applications/Cocos/Creator/3.8.8/` 安装的编辑器；其他位置通过 `COCOS_EDITOR` 环境变量指定可执行文件。`serve` 使用 Python 3，仅监听本机地址。

Cocos CLI 成功退出码为 36，构建脚本将其转换为正常成功，并把完整日志写入 `.mvp/build.log`。构建启用资源 MD5 文件名，避免更新后继续命中旧的游戏脚本。使用官方 CLI 的方式见 [Cocos 命令行构建文档](https://docs.cocos.com/creator/3.8/manual/en/editor/publish/publish-in-command-line.html)。

## 操作与验收

- 每局随机 **30 个总节点、12 层分岔**，沿连线选择下一层；本局地图固定，重新出发或刷新生成新图。
- 地图支持鼠标/单指拖动、双指捏合、滚轮与 +/− 按钮缩放（55%～150%）、定位当前；拖动/缩放后不误选节点。地图不展示宠物列表和介绍段落。
- 新远征初始 **60 灵露**，此后跨节点保留余额，不再按场重置。将底部猫、兔、鹿或菇头像拖到空树桩后松手（也可点击头像，再点击空树桩），消耗 **30 灵露**召唤一只；同种可重复召唤，初始可用 **8 个树桩**，开垦后最多 **16 只**，每个空树桩放一只。
- 一半树桩被**荒藤**缠住，普通宠物不能放置或搬入。新增 **掘芽鼹**：拖头像到荒藤树桩、或选头像后点树桩，花 **20 灵露**开垦；它随后钻回森林，不占场上或后备。开垦结果在本局跨节点保留，释放场地上的宠物也不重新封锁。
- **归林绳索**免费使用：拖绳索到宠物，或点绳索再点宠物，返还原召唤费用 **60%**（当前 **18 灵露**）；也可长按宠物拖到绳索。后备选择伙伴后卡片可放生，或先选绳索再开后备直接选择。放生不重复返还，暂停不能操作；收回后备仍不退款。
- 灵露不足时，底部头像盖半透明暗色蒙层，**无法拖出**，仍可点击查看；够用后恢复。通用 Toast 保留，已有宠物仍可免费搬迁。
- 战斗中仍可召唤；**不再每秒自动获得灵露**。击杀普通/疾行 +6，岩甲/回春 +8，精英 +25，BOSS +60，漏怪不发奖励。
- 蓝色“静露营地”为休息节点，二选一：**获得 45 灵露**或**回复 1 点树心**。满血时回血置灰，每处只能领取一次；第 4 站保证营地，第 2/8/11 站部分分支可选择营地，休息无宠物栏。
- 范围指示器默认隐藏，点击场上宠物时显示在其脚下，拖动时随落点显示；放下、取消或点击道路空白时收起。底部头像点击切换数据，不在战场中央创建预览圈。
- 拖动时显示头像、空树桩高亮和目标射程；只有在有效空树桩松手并通过余额/容量检查才扣款。松在道路或占用位置、拖回卡片或取消手势均不扣款。
- 点击头像或场上宠物，顶部卡片显示名称、攻击/施法数值和效果，场上显示范围。场上宠物**长按 0.3 秒再拖到空树桩**搬迁，也可选中后点击空位；点击原位仅查看，卡片“收回”进入后备。不退款、不重复收费，战斗中搬迁/撤回/重新部署有 **1 秒停手**。
- 橙色爪爪猫近战挥击，蓝色星弹兔远程发射追踪弹。点击头像切回召唤模式，点击场上或后备宠物进入搬迁模式。
- **铃芽鹿**不攻击：185 范围内其他宠物攻击力 **+40%**，多只鹿不叠加；受益宠物显示绿色环，数据卡显示增强后的伤害。
- **茸茸菇**施放孢子：145 范围内所有敌人每 **0.5 秒受到 8 点伤害**；出圈停止，可接受鹿增益。宠物均无生命值，不会扣血。
- 雾兽起始 **96 血**并随层数成长；新增疾风雾狐、岩甲雾龟、回春雾灵、巨角雾犀精英和噬雾之王 BOSS。岩甲抗直击、孢子可穿甲，回春怪脱战再生，BOSS 半血加速。第 **3、9** 站固定精英，第 **6、12** 站固定 BOSS；地图提前标注，点击敌人查看血量与能力。详见 [首轮数值](docs/BALANCE.md)。
- 点击“开始防守”进入战斗。支持暂停、1/2 倍速；暂停期间不能放置或搬迁；`1` / `2` / `3` / `4` / `5` 选择猫、兔、鹿、菇、鼹鼠，空格开战或暂停。
- 宠物及其位置跨节点保留；下一场继承剩余灵露与树心。本局最多持有 16 只（含后备，与全部树桩数相同）。
- 基地树心 **3 / 3**，每只敌人突破扣 1，归零时结束，可重新选路。允许空阵开战以验证失败流程。
- 沿所选分支经过 12 层战斗/休息节点后进入远征完成画面，可以重新开始。
- 路线由下向上选择；战场从**左上入口**折返通向**右下摇篮树**，提供 **16 个树桩**。树心、灵露和选中数据位于上方，底部展示五个伙伴头像、归林绳索和战斗控制。
- 点击“后备 N”打开伙伴弹窗，再选择实例并点击树桩免费部署；弹窗阻止背景点击，不会自动暂停战斗。
- 横屏时自动暂停，转回竖屏后恢复此前运行中的战斗；如果转屏前已手动暂停，仍保持暂停。

## 检查命令

```sh
npm run typecheck
npm run typecheck:tests
npm test
# 开发时监听测试变化
npm run test:watch
```

测试使用 [Vitest](https://vitest.dev/guide/) 5.1.0，配置为 `vitest.config.mts`，只在 Node 环境运行 `tests/**/*.test.ts`。已在 Node.js 24.11.0 验证。`npm test` 单次运行后退出，`npm run test:watch` 进入监听模式。游戏源码和测试分别通过根配置、`tsconfig.test.json` 检查。

根 `tsconfig.json` 保留 Cocos 3.8.8 生成配置的继承，显式使用 `module: ESNext`、`moduleResolution: bundler`，修复旧 node/node10 解析方式在 TypeScript 7 中被移除的问题；不修改 `temp/`，不添加 `ignoreDeprecations`。已验证项目本地 TypeScript 5.9.3 与全局 7.0.2。

52 项测试覆盖灵露收支、战斗中召唤、暂停冻结、容量、免费搬迁与停手、跨关保留、路线锁定、近远程差异、树心归零失败及完整通关，鹿增益不叠加与搬迁失效、菇多目标持续伤害、暂停、击杀去重及弹道快照，Toast 自动消失/重复合并/替换与清理，随机地图 500 种子结构检查、视口平移缩放，新增半数封锁、开垦扣费与持久状态、16 只部署/后备容量、放生去重/退款/暂停与光环移除，以及竖屏方向判定、树桩触点与攻击距离等比投影。新增敌种速度、护甲/穿甲、再生延迟、BOSS 狂暴、击杀去重，以及仅击杀/休息收入下 100 种子完整远征回归；全局余额（包括 0）继承、休息二选一去重、满血拒绝、漏怪无掉落与树心跨关。根 tsconfig 保留引擎生成配置继承；`skipLibCheck` 仅跳过 3.8.8 自带声明的内部缺失引用，项目源码仍参与类型检查。
