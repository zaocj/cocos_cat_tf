# 萌宠变异录 MVP

基于 Cocos Creator **3.8.8** 的无素材塔防原型。宠物、敌人、道路和摇篮树均由 Graphics 绘制。

**当前仅支持竖屏。** 设计分辨率 720×1280；横屏或正方形窗口显示“请竖屏游玩”，战斗暂停。手机请竖持，桌面请使用竖向窗口。

## 运行

### 在 Cocos 中预览

1. 使用 Cocos Creator 3.8.8 打开本项目，等待脚本与资源导入。
2. 打开 `assets/Boot.scene`，Canvas 已挂载 `MvpGame`。
3. 点击编辑器的场景预览，选择竖屏手机设备或竖向的 Webpage Full Screen；横向窗口不能开始游玩。

### 运行独立 Web 版本

```sh
npm ci
npm run build:mvp
npm run serve
```

随后打开 [本地游戏](http://127.0.0.1:8090/)。构建默认使用本机 `/Applications/Cocos/Creator/3.8.8/` 安装的编辑器；其他位置通过 `COCOS_EDITOR` 环境变量指定可执行文件。`serve` 使用 Python 3，仅监听本机地址。

Cocos CLI 成功退出码为 36，构建脚本将其转换为正常成功，并把完整日志写入 `.mvp/build.log`。构建启用资源 MD5 文件名，避免更新后继续命中旧的游戏脚本。使用官方 CLI 的方式见 [Cocos 命令行构建文档](https://docs.cocos.com/creator/3.8/manual/en/editor/publish/publish-in-command-line.html)。

## 继续游戏与首次引导

启动进入首页：新远征，或读取已有存档继续。右上角菜单可保存并回首页、重新查看指引。刷新后也可继续同一局，战斗先暂停；待选变异固定、不会重抽，口袋/本局放生/开垦/冷却和战斗进度保留。新远征会确认覆盖当前局，已读引导和 1/2 倍速设置保留。

自动保存发生在操作提交、击杀/漏怪、每个模拟秒和切后台；主档损坏会尝试上一份有效备份并提示，写入失败会暂停，支持重试或明确选择本次不保存试玩。当前为设备本地存档，没有跨设备云同步。细节见 [存档与指引](docs/SAVE_AND_GUIDE.md)。

首次指引仅在相关场景出现，可跳过；完成后不会变成常驻 HUD 文案。右上角菜单可以重新显示。

## 新宠物与伙伴驿站

- **藤蔓墙兽**：绿色阻挡宠物，每 7 秒在前方雾兽脚下伸出藤蔓拦路 2 秒，不造成伤害；二/三星间隔 6/5 秒。缠生变异延长存活、增加间隔；迅芽变异缩短间隔、缩短存活。
- **电绒雀**：黄色连锁输出，190 范围、24 攻击、1.2 秒间隔，最多连锁 3 只敌人，每跳保留 70% 伤害；雷羽变异每第三击多连锁 2 只。
- 新远征口袋只有 **爪爪猫、星弹兔**；紫色 **伙伴驿站** 节点可花 **20 灵露**加入一种宠物，之后再按原价 30 随机召唤。第 2/8 站与营地形成分支，第 11 站也有部分驿站。
- 驿站 **定向放生花 20 灵露**，确认后从本局召唤池移除，本局不能重购；已经放到场上的实例保留。至少保留一种输出。新远征恢复猫/兔；继续同一局会保留口袋与本局放生名单。这与绳索放生一个实例并返还 60% 不同。

## 精简 HUD

战斗页不显示游戏标题、常驻宠物资料卡及底部操作提示；顶部只留两行关键信息，底部只留头像/工具和战斗按钮。点击伙伴或敌人临时查看资料，可关闭或点空白收起，收回/合成仍在资料浮层内。地图纵向填充腾出的空间，射程使用对应椭圆投影，玩法距离和伤害不变。

## 操作与验收

- 每局随机 **30 个总节点、12 层分岔**，沿连线选择下一层；本局地图固定，重新出发或刷新生成新图。
- 地图支持鼠标/单指拖动、双指捏合、滚轮与 +/− 按钮缩放（55%～150%）、定位当前；拖动/缩放后不误选节点。地图不展示宠物列表和介绍段落。
- 新远征初始 **60 灵露**，此后跨节点保留余额，不再按场重置。最多携带 **6 种**宠物，新远征初始只有猫、兔；点击“随机召唤”花 **30 灵露**从携带池抽一只，自动放在首个开放空树桩。没有空位会 Toast，失败不扣费、不抽取；同种可重复召唤，初始可用 **8 个树桩**，开垦后最多 **16 只**，每个空树桩放一只。
- **同种同星两只合成一只**，最高 **3 星**，不额外花灵露。长按拖到同种同星伙伴上，或选中主宠点击数据卡“合成”，再选场上/后备素材。保留目标位置，头顶数字 **1/2/3** 显示星级；伤害倍率 **1/1.9/3.8**，鹿助威 **40%/60%/85%**。
- 合成默认 **50%** 触发变异，在两张卡中选择一张；弹窗期间战斗冻结。属性卡用速度/范围换高攻击/助威，特性卡为猫震荡爪、兔双星弹、菇蔓延孢雾、鹿灵铃共鸣。最多一个变异，后续选择替换旧变异。概率配置在 [PetGrowth.ts](assets/scripts/domain/PetGrowth.ts) 的 `PET_GROWTH.mutationChance`（0～1）。
- 合成后按素材总投入计算放生返还：二星 **36**、三星 **72** 灵露。战中合成停手 1 秒，不能借合成重置冷却。
- 一半树桩被**荒藤**缠住，普通宠物不能放置或搬入。使用独立 **林地铲**：拖铲子到荒藤树桩，或选铲子后点树桩，每次花 **40 灵露**开垦；不占召唤池、场上或后备，已移除掘芽鼹。开垦结果在本局跨节点保留，释放场地上的宠物也不重新封锁。
- **归林绳索**免费使用：拖绳索到宠物，或点绳索再点宠物，返还原召唤费用 **60%**（当前 **18 灵露**）；也可长按宠物拖到绳索。后备选择伙伴后卡片可放生，或先选绳索再开后备直接选择。放生不重复返还，暂停不能操作；收回后备仍不退款。
- 灵露不足时，随机召唤按钮（30）和铲子（40）分别灰显；铲子不足不能拖动，按钮点击仍 Toast 提示。携带头像只查看资料，不能拖动召唤或付费进化。通用 Toast 保留，已有宠物仍可免费搬迁。
- 战斗中仍可召唤；**不再每秒自动获得灵露**。击杀普通/疾行 +6，岩甲/回春 +8，精英 +25，BOSS +60，漏怪不发奖励。
- 蓝色“静露营地”为休息节点，二选一：**获得 45 灵露**或**回复 1 点树心**。满血时回血置灰，每处只能领取一次；第 4 站保证营地，第 2/8/11 站部分分支可选择营地，休息无宠物栏。
- 范围指示器默认隐藏，点击场上宠物时显示在其脚下，拖动时随落点显示；放下、取消或点击道路空白时收起。底部头像点击切换数据，不在战场中央创建预览圈。
- 场上宠物拖动时显示合法搬迁/合成目标和射程；工具拖动高亮可开垦/放生目标。松在无效位置或取消手势均不扣款。
- 点击头像或场上宠物，按需资料浮层显示名称、攻击/施法数值和效果，场上显示范围。场上宠物**长按 0.3 秒拖到空树桩**搬迁，拖到异种宠物上交换位置（双方星级和变异保留），也可选中后点击空位；点击原位仅查看，卡片“收回”进入后备。不退款、不重复收费，战斗中搬迁/撤回/重新部署有 **1 秒停手**。
- 橙色爪爪猫近战挥击，蓝色星弹兔远程发射追踪弹。点击携带头像只查看物种资料，点击场上或后备宠物进入搬迁模式。
- **铃芽鹿**不攻击：185 范围内其他宠物攻击力 **+40%**，多只鹿不叠加；受益宠物显示绿色环，数据卡显示增强后的伤害。
- **茸茸菇**施放孢子：145 范围内所有敌人每 **0.5 秒受到 8 点伤害**；出圈停止，可接受鹿增益。宠物均无生命值，不会扣血。
- 雾兽起始 **96 血**，普通血量按每层约 **+20%** 复合成长，末站 **713～721 血**；末关 BOSS **3922～3966 血**，后段移速提高、出怪间隔缩至 **1.54 秒**；新增疾风雾狐、岩甲雾龟、回春雾灵、巨角雾犀精英和噬雾之王 BOSS。岩甲抗直击、孢子可穿甲，回春怪脱战再生，BOSS 半血加速。第 **3、9** 站固定精英，第 **6、12** 站固定 BOSS；地图提前标注，点击敌人查看血量与能力。详见 [首轮数值](docs/BALANCE.md)。
- 点击“开始防守”进入战斗。支持暂停、1/2 倍速；暂停期间不能放置或搬迁；`1` / `2` / `3` / `4` / `5` 查看猫、兔、鹿、菇、选择铲子；`R` 随机召唤，空格开战或暂停。
- 宠物及其位置跨节点保留；下一场继承剩余灵露与树心。本局最多持有 16 只（含后备，与全部树桩数相同）。
- 基地树心 **3 / 3**，每只敌人突破扣 1，归零时结束，可重新选路。允许空阵开战以验证失败流程。
- 沿所选分支经过 12 层战斗/休息节点后进入远征完成画面，可以重新开始。
- 路线由下向上选择；战场从**左上入口**折返通向**右下摇篮树**，提供 **16 个树桩**。节点、树心、波次和灵露集中在顶部两行，选中资料按需浮层显示，底部展示六个口袋槽位、铲子、归林绳索和战斗控制。
- 点击“后备 N”打开伙伴弹窗，再选择实例并点击树桩免费部署；弹窗阻止背景点击，不会自动暂停战斗。
- 横屏时自动暂停，转回竖屏后恢复此前运行中的战斗；如果转屏前已手动暂停，仍保持暂停。

## 检查命令

```sh
npm run typecheck
npm run typecheck:tests
npm test
# 开发时监听测试变化
npm run test:watch
# 两宠开局真实随机循环，输出 .mvp/random-balance.json
npm run balance
```

测试使用 [Vitest](https://vitest.dev/guide/) 5.1.0，配置为 `vitest.config.mts`，只在 Node 环境运行 `tests/**/*.test.ts`。已在 Node.js 24.11.0 验证。`npm test` 单次运行后退出，`npm run test:watch` 进入监听模式。游戏源码和测试分别通过根配置、`tsconfig.test.json` 检查。

根 `tsconfig.json` 保留 Cocos 3.8.8 生成配置的继承，显式使用 `module: ESNext`、`moduleResolution: bundler`，修复旧 node/node10 解析方式在 TypeScript 7 中被移除的问题；不修改 `temp/`，不添加 `ignoreDeprecations`。已验证项目本地 TypeScript 5.9.3 与全局 7.0.2。

111 项测试覆盖灵露收支、战斗中召唤、暂停冻结、容量、免费搬迁与停手、跨关保留、路线锁定、近远程差异、树心归零失败及完整通关，鹿增益不叠加与搬迁失效、菇多目标持续伤害、暂停、击杀去重及弹道快照，Toast 自动消失/重复合并/替换与清理，随机地图 500 种子结构检查、视口平移缩放，新增合成事务/3 星上限/冻结选择、1000 种子概率复现与四种特性战斗效果、半数封锁、开垦扣费与持久状态、16 只部署/后备容量、放生去重/退款/暂停与光环移除，以及竖屏方向判定、树桩触点与攻击距离双轴投影。新增敌种速度、护甲/穿甲、再生延迟、BOSS 狂暴、击杀去重，以及仅击杀/休息收入、持续升星下 0%/50% 变异各 100 种子完整远征回归；全局余额（包括 0）继承、休息二选一去重、满血拒绝、漏怪无掉落与树心跨关。根 tsconfig 保留引擎生成配置继承；`skipLibCheck` 仅跳过 3.8.8 自带声明的内部缺失引用，项目源码仍参与类型检查。

随机召唤使用独立种子流；没有任何已持有输出时保证抽到输出，防止辅助开局卡死。口袋初始由 Session 的 carriedPets 配置（1～6 种且含输出），游玩时通过伙伴驿站调整。
