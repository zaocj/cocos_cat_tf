## 执行的检查

- `npm test`：7 项通过，包括完整三场通关、无防守失败、终点与致死弹道同一步的边界回归。
- `npm run typecheck`：通过。保留根配置对 Cocos 生成配置的继承；跳过检查引擎自带声明内部错误，不跳过项目 TypeScript 源码。
- 资源验证：6 个唯一 UUID，所有 assets 文件/目录配套 meta；场景内部索引、父子关系、组件归属和 Scene ID 均合法。
- `npm run build:mvp`：通过，包装 Cocos CLI 成功码 36，输出 `build/web-mobile`，日志 `.mvp/build.log`。
- 编辑器预览：路线 → 部署 → 胜利 → 续关，空阵失败。独立发布版本：路线 → 部署 → 胜利、最终修复后的空阵失败与重新开始。
- 画面检查：1280×800、1024×768、844×390 横屏，以及当前应用默认 694×736 窗口；使用等比缩放留边，无主内容裁切。
- 界面独立评审：森林棋盘、路线可选状态、两宠选择/部署和射程符合已确认方向；提出的唯一重要问题为终点结算顺序，已修复并复查通过。

## 已知限制与后续

- 当前以桌面与横屏使用为主，窄屏等比缩小时文字较小；尚未进行手机竖屏界面重排或真实手机触控验证。
- 游戏使用鼠标点击与 Cocos 触摸事件放置，没有拖拽操作；键盘仅提供 1/2 选宠与空格开战/暂停，没有完整键盘焦点导航。
- 不保存进度，刷新重新开始。没有合成、变异、捕捉、货币、遗物与局外成长。
- 测试浏览器在模拟视口切换时产生 Cocos `Unexpected screen orientation: 13` 警告；未见阻断游戏的脚本错误，真实移动设备方向切换尚待验证。
- Web Desktop 默认模板出现固定尺寸与页面滚动，因此实际交付使用全窗口 Web Mobile 模板；该模板同样可在桌面浏览器运行。
