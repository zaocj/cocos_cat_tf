# 无素材 MVP 验收记录

日期：2026-11-05。编辑器：Cocos Creator 3.8.8。验收范围为本次用户指定的四项最小玩法，不代表完整 V0.1 已完成。

## 2026-11-06 召唤头像蒙层与通用 Toast

- 灵露低于 30 时四个召唤头像覆盖半透明暗色蒙层，够用自动移除；蒙层不接收输入，仍可查看资料与触发不足提示。已有宠物免费搬迁不受影响。
- 通用 GameToast 是独立非阻塞顶层，支持 info/warning/success、消息/时长配置；默认 2.4 秒，淡入/淡出，相同提示不续时，新提示替换。UI 时间独立于战斗暂停和倍速，转屏/后台/退出清理。
- 召唤头像在余额不足时拖入战场，即提示“灵露不足，还差 N 灵露”，每次拖动只提示一次；松手和点击不足统一由领域层拒绝且复用 Toast，不重复扣款。
- 编辑器预览也已实测两次召唤后头像蒙层和不足拖放 Toast，未见脚本错误；最终 Web 构建与 9 个唯一资产 UUID/meta 配对检查通过。
- 25 项 Vitest、源码及测试类型检查通过；新增 Toast 显隐/淡入淡出/重复合并/替换/清理测试。390×844 独立 Web 版已验证 60→30→0 后四头像变暗，灰显头像拖放弹 Toast、仍为两只宠物且余额 0；截图 `.mvp/dew-toast.jpg`。提示随后自行消失，灰显仍能查看资料；余额为 0 时成功把两只已有宠物搬到末段，战斗收入恢复后头像亮起，胜利后 60 灵露的新节点也正常（`.mvp/dew-restored.jpg`）。

- 场上最多 6 只，含后备最多持有 12；移动/交换/撤回/重新部署不收费、不返还灵露，战斗搬迁停手 1 秒。

- 领域测试更新为 14 项，全部通过；源码类型检查、Web 构建通过。包含战斗中新召唤、余额不足不扣款、满员不扣款、暂停不能放置和不能产出、每击杀仅奖励一次、撤回不能刷返还、跨关重置及首次漏怪结束。

## 已知限制与后续

- 当前只支持竖屏，已完成手机比例重排；尚未进行真实手机硬件与系统安全区验证。
- 底部召唤卡支持鼠标/触屏拖动到空树桩，也保留点击放置；场上搬迁与后备仍使用点击。键盘仅提供 1/2 选宠与空格开战/暂停，没有完整键盘焦点导航。
- 不保存进度，刷新重新开始。已加入灵露；没有合成、变异、捕捉、其他货币、遗物与局外成长。
- 测试浏览器在模拟视口切换时产生 Cocos `Unexpected screen orientation: 13` 警告；未见阻断游戏的脚本错误，真实移动设备方向切换尚待验证。
- Web Desktop 默认模板出现固定尺寸与页面滚动，因此实际交付使用全窗口 Web Mobile 模板；该模板同样可在桌面浏览器运行。
