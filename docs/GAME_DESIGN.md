## 1. 游戏概念

**一句话介绍：带着一棵会行走的家园树，沿分岔路线寻找萌宠，把相同萌宠合成升级，在不可预测的变异中组建独一无二的塔防阵容。**

《萌宠变异录》是一款单人、局内构筑的萌宠合成塔防游戏。玩家在探索地图上选择路线，经历战斗、捕捉、奇遇、交易与休整；进入战斗后，把拥有的萌宠放置在敌人道路两侧，守住家园。萌宠通过同种、同星合成成长，合成时可能发生变异。

变异不是单纯的稀有品质升级。例如，原本均衡的小猫可以变成攻击翻倍、攻击速度下降的“巨爪猫”，也可能变成攻击速度极快、单次伤害下降的“躁动猫”。玩家要根据变异结果重新安排位置、捕捉伙伴、调整后续路线。

### 1.1 V0.1 的设计目标

1. **合成前有期待：** 这次升星会得到稳定成长，还是一个值得围绕它构筑的变异？
2. **变异后有决策：** 新能力改变这只萌宠的用途，而不只是换一种颜色。
3. **路线选择有依据：** 缺少合成材料就去捕捉，树心告急就去休整，阵容成熟就挑战精英。
4. **塔防布局有价值：** 相同阵容通过站位、火力分工和针对性调整，可以应对不同敌人。
5. **失败后能理解原因：** 玩家知道自己缺少清群、攻坚或覆盖能力，并愿意开启下一次远征。

## 2. 世界观与家园概念

### 2.1 背景：寻找净土的摇篮树

森林被“异化孢雾”侵蚀。孢雾让野外生物变得躁动，也让萌宠出现奇异的适应性变化。玩家是一名护林饲育员，带着最后一棵能够孕育新森林的**摇篮树**向净土远征。

摇篮树的枝叶间挂着小窝、吊床和种子屋，是萌宠共同生活的家园。探索时，它收起根须缓慢前进；战斗时，它扎根在道路终点，萌宠则前往沿途的守护树桩抵御雾兽。

### 2.2 基地血量：树心值

- 树心值是整局唯一的失败生命资源，初始值与上限均为 **30**。
- 敌人抵达道路终点，会吞噬树心并离开战场；扣除的数值跨战斗保留。
- 普通雾兽扣 1，重型雾兽扣 2，精英个体扣 3，区域首领扣 8；具体数值在敌人预告中可见。
- 树心降至 0，远征立即失败；即使这是最后一只敌人，也不会先结算胜利。
- 休整、部分奇遇和遗物可恢复树心，恢复不能超过上限。
- 萌宠本身没有生命值，不会永久死亡，也不承担道路阻挡。玩家关注阵容与布局，不需要额外管理宠物治疗。

**情感表现：** 高树心时枝叶明亮、萌宠在小窝互动；低于或等于 10 点时叶片卷曲、树心闪烁。漏怪表现为树心光点被吸走，避免血腥表达。

### 2.3 终局目标

击退第二个区域的首领“噬雾之核”，护送摇篮树抵达净土，完成一次远征。通关结算展示本局最有代表性的变异萌宠、完整路线与守护记录。

```text
          根据阵容短板与树心状态选择下一个节点
                         ↓
           击败区域首领 → 进入下一区域 → 最终首领
                         ↓
                通关或失败 → 图鉴记录 → 新远征
```

其中最重要的因果链是：**变异产生新优势与短板 → 捕捉互补伙伴 → 改变布阵 → 选择适合的风险与奖励 → 获取下一次合成机会。**

### 3.2 一场战斗的循环

1. 查看地图、每波敌人种类、数量、入口与漏怪伤害。
2. 在准备阶段部署萌宠、调整位置、合成；满意后主动开战。
3. 萌宠自动攻击，敌人沿固定路线前进。玩家可暂停观察、切换 1 倍或 2 倍速。
4. 本波敌人全部被消灭或抵达终点，进入波间准备；允许重新布阵与合成。
5. 最后一波结束且树心大于 0，领取节点奖励，返回探索地图。

战斗中不掉落萌宠、没有击杀金币，也不开放临时抽卡。主要操作集中在准备阶段，避免首版同时承担高速操作和构筑判断。

### 3.3 三种时间尺度的决策

| 时间尺度 | 玩家在想什么 | 核心选择 |
| --- | --- | --- |
| 当前波次 | 这波怪怎么拦住？ | 覆盖位置、优先目标、减速与输出衔接 |
| 当前区域 | 我的阵容缺什么？ | 多留一只还是合成、捕捉哪种宠、是否挑战精英 |
| 整次远征 | 我能靠什么通关？ | 主力变异方向、遗物搭配、树心与资源分配 |

## 4. 探索路线与节点

### 4.1 路线结构

采用爬塔式分岔地图：节点按层排列，只能沿连线前往下一层，经过的节点不能回头。借鉴的是“看见机会与风险，再主动选路”的结构，具体内容围绕萌宠捕捉和变异构筑设计。

- 每个区域有 8 层，普通分岔层有 2～3 个候选节点。
- 每层只进入一个节点，因此一次远征固定经历 16 个节点。
- 同层不同节点可以连接下一层的不同分支，不能跨层跳过。
- 当前区域全部节点类型、连线和首领机制可见；未到达的奇遇不提前展示具体选项。
- 战斗节点在地图上展示主要威胁标签，例如“虫群”“重甲”“高速”；进入准备阶段后展示精确波次。
- 不在选择节点后生成针对当前阵容的克制敌人；地图与遭遇在开局生成。

### 4.2 每区固定节奏

| 层数 | 候选节点 | 节奏目的 |
| --- | --- | --- |
| 1 | 普通战斗 | 检验当前阵容，获得基础资源 |
| 2 | 捕捉地 / 普通战斗 | 立即补充伙伴，或赚取金币 |
| 3 | 奇遇 / 普通战斗 | 接受有代价的机会，或选择确定收益 |
| 4 | 普通战斗 | 中段阵容检验 |
| 5 | 休整营地 / 游商 | 恢复容错，或把积蓄转为战力 |
| 6 | 捕捉地 / 普通战斗 | 为首领补足合成材料或功能位 |
| 7 | 精英战斗 / 普通战斗 | 用更高风险换取遗物与催化资源 |
| 8 | 区域首领 | 检验构筑并结束本区域 |

以上是节点类型模板，不要求每条横向连线都可达。生成后必须保证：每条从入口到首领的完整路线，至少经过一次捕捉地，并能在第 5 层选择休整营地；每个节点都有前进路径，无孤立节点和死路。首版每区预计 4～7 场战斗，整局约 8～14 场。

### 4.3 节点详细规则

| 节点 | 玩家行为 | V0.1 收益与代价 |
| --- | --- | --- |
| 普通战斗 | 完成 3 波防守 | 固定获得 15 金币，并从 3 只一星萌宠中选择 1 只；可放弃萌宠 |
| 捕捉地 | 从 3 组候选伙伴中选择 1 组 | 免费获得同种一星萌宠 2 只；可额外花 15 金币，追加同种一星萌宠 1 只 |
| 精英战斗 | 完成 4 波强化防守 | 25 金币、1 份催化露、遗物三选一；没有额外萌宠奖励 |
| 奇遇 | 阅读情境并选择一个选项 | 交换树心、金币或萌宠，获得确定展示的收益；永远有无损离开选项 |
| 游商 | 按明码标价购买 | 购买萌宠、催化露或移除变异；离开不收费 |
| 休整营地 | 三选一 | 恢复 8 树心 / 获得 1 份催化露 / 免费移除一只萌宠的变异 |
| 区域首领 | 完成 3 波护卫战与第 4 波首领战 | 第一区域：30 金币、遗物三选一、恢复 5 树心；第二区域：通关结算 |

捕捉地不额外设计投掷或概率失败小游戏。首版要验证的是“抓谁、是否抓同种、能否形成变异”，捕捉动画负责表现收获感。

### 4.4 供给与防断档

- 开局获得一星爪爪猫 2 只、泡泡兔 1 只、绵绵羊 1 只，初始 30 金币、1 份催化露。
- 第一次进入捕捉地时，三组候选中至少有一组为爪爪猫，方便继续完成三星目标。
- 后续捕捉地至少一组候选为玩家当前持有、且仍可合成的物种；其余候选从全物种池抽取，同一节点不重复物种。
- 普通战斗的萌宠三选一至少提供一个当前持有物种；奖励生成后固定，重新读档不会刷新。
- 如果玩家已无萌宠，奖励的保底物种回退为爪爪猫，捕捉候选正常生成；允许继续招募恢复阵容。
- 路线不要求玩家必须合出指定变异才能过关。无变异阵容应能通过合理升星、捕捉和布阵完成基础难度。

## 5. 塔防战斗

### 5.1 战场结构

- 俯视 2D 地图，敌人沿可见固定道路移动，萌宠放置在道路两侧的固定“守护树桩”上。
- 每张图有 8～10 个树桩；最多同时部署 **6 只萌宠**，一个树桩放置一只。
- 道路不可摆放、不允许堵路或改变寻路。V0.1 不加入飞行、隐形和多层地形。
- 首版使用 3 个布局模板：长弯道、双回环、双入口汇流。双入口最终共用一个终点与树心。
- 不同地图依靠弯道覆盖、树桩间距和入口位置产生差异，不额外叠加随机地形增减益。

### 5.2 部署、合成与操作边界

- 战前和波间可免费部署、撤下、换位、合成与调整目标优先级，无准备时间限制。
- 合成消耗两只萌宠，生成一只高星萌宠；如果主素材已部署，结果保留在主素材的位置，副素材位置腾空。
- 波次进行中不可移动、撤下、合成或改变目标优先级；暂停只用于查看信息，不解锁准备操作。
- 玩家可以随时查看射程、当前变异、敌人状态与预计漏怪伤害。
- 第一波开始后不能主动退出节点返回地图；可以暂存退出游戏，再回到同一状态。
- 首版无主动技能、法力条与临时建造费用；每只萌宠自带一个自动触发的物种能力。

### 5.3 战斗基础规则

| 规则 | 设定 |
| --- | --- |
| 默认索敌 | 射程内距离终点最近的敌人 |
| 可选索敌 | 最靠近终点 / 生命最多 / 护甲最高 |
| 射程计算 | 以树桩中心到敌人中心的距离判断，文中 1 格为统一长度单位 |
| 攻击方式 | 攻击开始时锁定目标，已发射投射物持续追踪；目标死亡则消失，不重新索敌 |
| 护甲结算 | 每次命中伤害 = max(1, 最终攻击力 − max(0, 护甲 − 穿甲)) |
| 暴击与命中 | 首版不加入，降低数值噪声 |
| 群体伤害 | 同一次范围命中对每个敌人单独计算护甲 |
| 减速 | 同时存在时只取最强减速，不相加；持续时间按各自来源刷新 |
| 减速上限 | 普通敌人最多降低 60% 移速；首领最多降低 30% |
| 波次结束 | 所有敌人均死亡或离开；清除临时状态，所有萌宠攻击计时重置为可攻击 |

若两名敌人离终点距离相同，则优先更早出生的敌人，保证表现与复现一致。伤害计算保留小数，界面显示取整。

### 5.4 敌人组合的设计原则

每种主力都应有适合与不适合的目标：大单次伤害对重甲有效，高攻速擅长清理分散小怪，群伤克制密集虫群，减速为短射程主力创造更多攻击时间。战斗预告让玩家在开战前做出调整，不靠突然出现的未知克制制造失败。

## 6. 萌宠、星级与合成

### 6.1 萌宠的三个维度

| 维度 | 决定内容 | 首版限制 |
| --- | --- | --- |
| 物种 | 基础属性、自动能力、战术职责 | 6 种，全部在初始局内池开放 |
| 星级 | 可靠的基础强度成长 | 一星、二星、三星 |
| 变异 | 同一物种内部的优势与短板变化 | 每只最多 1 个变异词条 |

同一物种没有额外的 SSR / R / 品质分级。星级负责稳定成长，变异负责玩法分化，避免多个稀有度系统互相掩盖。

### 6.2 合成规则

1. **两只同物种、同星级萌宠，可以合成一只高一星萌宠。** 两只一星变二星，两只二星变三星；三星不能继续合成。
2. 变异不同不影响合成资格；不同物种不能合成。
3. 合成不花金币，不存在失败或掉星。
4. 合成前指定主素材，用于决定默认继承的变异与部署位置；可在预览中交换主副素材。
5. 合成预览展示：消耗对象、升星后基础属性、默认继承、变异概率、保底进度、是否使用催化露。
6. 确认合成后不可撤销。即使没有发生变异，也始终得到高一星萌宠。

### 6.3 星级成长

| 星级 | 等效一星投入 | 攻击力倍率 | 攻击速度、射程 | 设计意图 |
| --- | --- | --- | --- | --- |
| 一星 | 1 只 | ×1.00 | 使用物种基础值 | 铺开覆盖、补充功能 |
| 二星 | 2 只 | ×2.20 | 不因星级变化 | 集中火力，释放一个部署位 |
| 三星 | 4 只 | ×4.80 | 不因星级变化 | 形成主力，回报持续投入 |

物种能力的伤害跟随攻击力；控制时长、触发频率、范围和辅助比例不随星级自动放大。因此，两只控制宠合成后会减少控制覆盖，这是要保留的选择。三星不是所有情况下都应该立刻追求的答案。

### 6.4 队伍容量与放归

- 最多持有 **12 只萌宠**，其中最多 6 只部署，其他进入后备栏。部署与后备共同计入 12 只上限。
- 准备阶段、探索地图和奖励结算界面均可整理、合成或放归；波次进行中不可操作。
- 放归一星 / 二星 / 三星萌宠分别获得 3 / 6 / 12 金币，变异不提高返还价格。
- 队伍满员时，新获得的萌宠先停留在奖励待领取区。玩家必须先整理队伍，或放弃未领取奖励，不能把待领取区当永久仓库。
- 捕捉所得一组萌宠逐只领取；可以在领取之间合成。追加捕捉仅在确认领取且容量足够时扣费，防止扣费后无法接收。

## 7. 核心特色：变异系统

### 7.1 设计定义

**变异是一种永久到本局结束的偏科，不是战斗中的临时减益。** 它至少降低一项与实战有关的属性，并显著提高另一项属性，使萌宠更适合承担某种职责。

V0.1 的变异只通过合成产生。普通捕捉与商店购买的萌宠均为未变异一星，确保“捕捉材料 → 合成期待 → 变异构筑”是主要循环。

### 7.2 变异概率与保底

| 项目 | 规则 |
| --- | --- |
| 基础概率 | 每次合成有 20% 概率触发一次“新变异机会” |
| 催化露 | 合成前可消耗 1 份，本次概率增加 30 个百分点；通常为 50% |
| 基础上限 | 所有加成后的概率不超过 100% |
| 保底 | 全队连续 4 次合成未触发新变异机会，第 5 次必定触发 |
| 重置 | 只要触发新变异机会，失败计数归零；玩家是否采用新词条不影响重置 |
| 继承 | 单纯保留素材上的旧变异，不算触发新变异机会 |
| 催化保护 | 已到 100% 时禁用催化露，避免无意义消耗 |

保底进度在全队共享、跨节点保留、每次新远征清零。界面显示“已连续 3 次未触发，再过 2 次合成必有变异机会”，不用玩家猜测隐藏规则。

### 7.3 新变异、继承与替换

为了避免“随机毁掉核心宠物”的挫败，采用以下结算顺序：

1. 先确定升星结果：生成目标星级的物种基础属性。
2. 再确定默认词条：主素材有变异则继承；主素材没有变异则默认无词条。副素材变异不会自动叠加，想保留它必须在合成前交换主副素材。
3. 判定是否触发新变异机会。未触发则直接保留默认结果。
4. 若触发，从该物种适用词条池中等概率、不重复地抽取 2 个新词条，排除已继承的那个词条。
5. 玩家选择“新词条 A / 新词条 B / 保持默认”。第一次变异时，保持默认即得到普通高星萌宠。
6. 每只宠物最终仍只有 0 或 1 个词条。替换旧词条后，按物种与星级基础值重新计算，旧加减值全部移除。

这样既保留随机结果的惊喜，也让玩家有能力守住已经形成的构筑。机会触发后，即便选择保持默认，也会消耗已使用的催化露。

### 7.4 首版变异词条池

表中的“攻速”指每秒攻击次数；“射程”指攻击索敌半径。百分比均为乘法系数，例如攻击 +100% 表示攻击力 ×2。

| 词条 | 获得的优势 | 付出的代价 | 适用物种与战术变化 |
| --- | --- | --- | --- |
| 巨力型 | 攻击力 +100% | 攻速 −35% | 猫、兔、狐、刺猬、猫头鹰；偏向重甲攻坚，容易浪费伤害 |
| 躁动型 | 攻速 +100% | 攻击力 −35% | 猫、兔、狐、刺猬、猫头鹰；频繁命中，怕高护甲 |
| 长臂型 | 射程 +70% | 攻击力 −25% | 猫、兔、狐、刺猬、猫头鹰；覆盖多段道路，单点火力变弱 |
| 贴贴型 | 攻击力 +90% | 射程 −40% | 猫、兔、狐、刺猬、猫头鹰；依赖弯道与减速伙伴 |
| 大泡泡型 | 泡泡减速时长 +120% | 攻速 −40% | 兔；对少量强敌维持长减速，对分散敌人覆盖不足 |
| 炸毛型 | 爆炸半径 +80% | 攻击力 −30% | 狐；更擅长密集虫群，单体输出下降 |
| 偏心型 | 助威攻击加成由 +15% 变为 +40% | 助威半径 −40% | 羊；服务紧密站位的小核心，不能覆盖全队 |
| 广播型 | 助威半径 +80% | 助威攻击加成由 +15% 变为 +8% | 羊；服务分散阵容，主力强化程度下降 |

绵绵羊仅使用后两种词条，每次变异机会都提供这两种中适用的候选；若已有其中一个词条，排除后只剩一个新候选，则展示“该新词条 / 保持默认”。其他物种至少有 4 个适用词条。

### 7.5 计算顺序与示例

计算顺序固定为：**物种基础值 → 星级倍率 → 自身变异倍率 → 遗物修正 → 羊的助威加成 → 敌方护甲与减速限制**。同类百分比遗物加成先相加，再与其他来源相乘；攻速最低 0.2 次/秒、最高 5 次/秒，攻击射程最低 1 格。

例如，一星爪爪猫基础攻击 10、攻速 1 次/秒、射程 3 格：

| 结果 | 攻击 | 攻速 | 无甲理论单体 DPS | 布阵意义 |
| --- | --- | --- | --- | --- |
| 普通二星猫 | 22 | 1.00 | 22.0 | 均衡主力 |
| 巨力二星猫 | 44 | 0.65 | 28.6 | 单次高伤，面对高护甲更强 |
| 躁动二星猫 | 14.3 | 2.00 | 28.6 | 快速清杂，对护甲损失更大 |
| 贴贴二星猫 | 41.8 | 1.00 | 41.8 | 射程缩至 1.8 格，依赖高停留时间位置 |

理论 DPS 不等于实际收益：射程、敌人密度、过量伤害、弹道与护甲都会改变表现。变异界面必须展示代价，不把所有结果都标成“战力提升”。

### 7.6 让变异影响整局，而不止一次合成

- 得到贴贴主力后，玩家更愿意捕捉泡泡兔延长敌人在短射程内的停留时间。
- 得到巨力主力后，玩家可以把它设为优先攻击护甲最高的敌人，让狐狸处理虫群。
- 得到广播羊后，分散站位的地图更容易充分利用全队，未必需要继续集中养一只主力。
- 不理想的变异可以暂时保留、通过下一次合成替换，或在营地与商店移除。
- V0.1 不开放词条叠加、定向购买指定变异或无限重抽，先验证单词条是否足够产生构筑差异。

## 9. 敌人、区域与首领

### 9.1 普通敌人

下表为第一区域基准值；速度单位为格/秒。节点难度通过血量系数、数量与混编调整。

| 敌人 | 生命 | 护甲 | 速度 | 漏怪伤害 | 设计职责 |
| --- | --- | --- | --- | --- | --- |
| 雾团 | 35 | 0 | 0.8 | 1 | 建立基础击杀节奏 |
| 疾跑芽 | 22 | 0 | 1.4 | 1 | 检验覆盖、快速索敌与减速 |
| 硬壳兽 | 100 | 8 | 0.55 | 2 | 检验单次伤害与穿甲 |
| 孢子虫 | 12 | 0 | 1.0 | 1 | 成群出现，检验群伤 |
| 护雾兽 | 90 | 2 | 0.7 | 2 | 使周围 1.2 格内其他敌人承受伤害降低 20%，不作用于自己；多个光环不叠加 |
| 雾角精英 | 260 | 6 | 0.65 | 3 | 精英节点的高压核心；不召唤额外无限敌人 |

第一区域第 1 层以雾团与少量疾跑芽教学，后续逐步加入虫群、硬壳与护雾。第二区域继承全部种类，以更多混编和更紧密出怪提高压力。

### 9.2 波次预算

- 第一区域普通节点每波约 6～12 个敌人；第二区域约 10～18 个。
- 每波集中在 15～25 秒内出完，之后等待场内敌人处理完毕。
- 第一区域敌人血量系数随层数从 1.0 增至约 1.8；第二区域从 2.0 增至约 3.2，护甲与移动速度不再统一倍率膨胀。
- 精英节点使用同层普通节点约 1.3 倍的生命预算，并把部分敌人替换为雾角精英。
- 每个节点必须配置固定波次表；以上区间用于制作初稿，最终以实际通关率和漏怪原因调节。
- 首版不使用无限刷怪和自适应追赶难度，不因玩家获得强变异而临时提高敌人属性。

### 9.3 第一区域：绒芽林地

**主题：** 熟悉宠物、完成第一次变异、理解单体与范围输出。

首领“贪叶大毛虫”：生命初值 1,200、护甲 4、速度 0.35，漏怪扣 8。它与有限数量的孢子虫一同进入第四波；生命首次降至 50% 时，移速提高 40%，不重复触发。

对策：提前清除虫群，再用集火与减速争取击杀时间。需要输出与控制搭配，但不要求特定物种。

### 9.4 第二区域：萤雾沼泽

**主题：** 根据变异方向优化阵容，处理混合敌人。

最终首领“噬雾之核”：生命初值 3,600、护甲 10、速度 0.3，漏怪扣 8。第四波开始后与固定编队的护雾兽、硬壳兽分批入场；自身每 10 秒进入持续 3 秒的雾壳状态，期间承受伤害降低 30%，提前 1 秒播放提示。雾壳与护雾兽光环相乘结算，最大减伤为 44%。

对策：群伤先清护卫，高单次伤害或穿甲处理首领，控制延长有效输出时间。最终胜利条件为第四波所有敌人已死亡或离场且树心大于 0；允许首领突破后依靠剩余树心险胜，结算标注“险守净土”。

## 11. 开局引导与完整流程示例

### 11.1 前 5 分钟

1. 摇篮树苏醒，用一句话交代目标：“把我们的家送到雾外去。”
2. 领取初始 4 只萌宠，看到两只猫的可合成提示。
3. 引导选择区域第一层的战斗节点，先自由摆放猫、兔与羊，显示射程和羊的助威范围。
4. 第一波主要是低血雾团，让玩家看到攻击、减速与树心终点。
5. 波间引导把两只猫合成二星，展示稳定升星与变异预览。
6. 首次教学中的这次合成固定触发新变异机会，在巨力与躁动中二选一，允许保持普通；不消耗催化露，并正常重置保底。
7. 此教学例外只用于首次教学远征，界面明确标注“首次教学赠送变异机会”；以后开局按标准概率执行。
8. 战后显示下一层“捕捉地 / 战斗”的差异，玩家开始自主选路。

第一波应保证初始阵容在合理覆盖道路时容易完成，不因尚未学习合成而漏大量怪。教学提示可以重看或关闭。

### 11.2 一次代表性远征

> 这是决策示例，不是必须按此结果出现的剧情脚本。

- 开局合出巨力二星猫，单体伤害充足，但攻击慢。
- 第一处捕捉地选择两只火绒狐，先分别部署，解决虫群压力。
- 奇遇获得催化露；之后把狐狸合成二星，触发炸毛型，确立“巨力猫攻坚、狐狸清群”的分工。
- 为了提高阵容覆盖，下一次捕捉选择泡泡兔；保留两只一星兔分守两个入口，而不是立即合成。
- 中段树心降至 17，在第五层选择营地恢复，而不是去商店。
- 首领前判断火力充足，挑战精英，获得射程遗物，扩大巨力猫的有效覆盖。
- 进入第二区域，捕捉爪爪猫补齐第二只二星猫，合成三星时指定巨力猫为主素材，保留核心方向。
- 面对最终首领，把猫设为优先攻击护甲最高，把狐狸设为最靠近终点；羊靠近主输出，兔覆盖护卫与首领汇流处。
- 即使最后少量怪漏过，只要树心仍大于 0，就能带着摇篮树抵达净土。

## 12. 局外成长、记录与重玩

V0.1 的重玩动力来自不同路线、奖励和变异组合，先不加入永久攻击力升级。

- **变异图鉴：** 记录见过的物种、实际采用过的变异外观与组合；只看到候选但没采用的不算收录。
- **远征记录：** 保存胜败、节点路线、最终树心、阵容、遗物、合成次数与变异选择。
- **结算卡片：** 展示本局贡献最高的萌宠和它的变异代价；贡献分别统计伤害、减速覆盖、助威覆盖，不把辅助宠简单判为低贡献。
- **继续远征：** 自动保存节点选择、准备阶段、波间与战斗状态。恢复后回到相同状态，不重新抽奖励。
- **随机一致性：** 地图、奖励、变异使用分开的随机序列并保存状态，调整站位或改变攻击次数不应改变下一次变异结果；重启游戏不会重抽。
- **新远征：** 清空局内资源与保底进度，重新领取相同初始队伍；图鉴与记录保留。

正式版可再评估横向内容解锁、新初始伙伴、变异外观收藏。首版不依赖长期刷数值解决关卡困难。

### 13.2 变异反馈的优先级

1. **形态可辨认：** 巨力型爪子变大，躁动型有抖动尾巴和急促步伐，长臂型拉长耳朵或前肢，炸毛型毛发蓬松。
2. **优势与代价并列：** 使用图标、箭头和明确数值，不能只依赖红绿颜色区分。
3. **动画服务于决策：** 合成先展示升星，再表现变异生长；首次可完整播放，后续允许跳过。
4. **萌感优先：** 变异是奇趣适应，不采用畸形、疼痛或恐怖表现。
5. **可追溯：** 宠物详情随时展示基础值、星级与各来源修正，帮助理解实际强弱。

### 13.3 玩家最常问的问题必须能直接回答

- “为什么不能合？”——指出物种不同、星级不同或已三星。
- “这次为什么不是 20%？”——列出催化露、遗物、保底的具体来源。
- “合完少了一只会不会更弱？”——并列展示属性变化与部署位变化，不给虚假的必胜判断。
- “为什么这只猫打不动硬壳？”——敌人详情展示护甲与该猫单次实际伤害。
- “刚才为什么输了？”——结算展示漏怪种类、累计损失及发生波次。

### 14.2 首版暂缓

- 复杂属性克制、元素反应、装备、天赋树、自动羁绊。
- 主动技能、战斗内抽宠、即时合成操作、动态堵路。
- 无限模式、每日挑战、多难度阶梯、多人协作、竞技对抗。
- 局外数值养成、付费抽宠、体力、赛季和排行榜。

### 14.3 建议的制作顺序

1. **验证合成塔防：** 先做一个弯道战场、猫兔狐、两次升星与巨力 / 躁动 / 贴贴变异，观察玩家是否主动改变布阵。
2. **接通路线闭环：** 加入一个区域与捕捉、营地、商店，让玩家完成第一次完整远征。
3. **验证构筑变化：** 补齐羊、刺猬、猫头鹰及全部变异、精英与遗物。
4. **形成 V0.1：** 补齐第二区域、最终首领、教学、图鉴、记录和可靠存档。

每一步都复用最终规则；临时内容不足时明确标为测试关，不让简化原型的特殊规则混入正式设计。

## 15. 验证标准与主要风险

### 15.1 先验证的四个问题

| 问题 | 观察方式 | 首轮期望信号 |
| --- | --- | --- |
| 玩家理解变异取舍吗？ | 变异选择后请玩家描述用途 | 多数玩家能说出至少一个优势和一个代价 |
| 变异真的改变玩法吗？ | 记录变异前后布阵、索敌、捕捉与选路变化 | 多数完整远征中至少出现 2 次有明确原因的调整 |
| 选路有真实权衡吗？ | 记录各分支选择及当时树心、阵容、金币 | 玩家会因资源和阵容改变选择，不总走同一类节点 |
| 失败是否可归因？ | 结算后简短回访，结合漏怪记录 | 玩家能指出覆盖、清群、攻坚或资源投入中的具体问题 |

### 15.2 建议记录的数据

- 每局耗时、到达层数、胜败、每节点树心变化。
- 每种节点的可选次数与实际进入次数，结合连线条件计算选择率。
- 合成次数、变异机会触发次数、候选词条、最终选择、放弃新变异比例。
- 催化露的获得与使用，保底触发情况，核心宠的升星时间。
- 每波伤害、各类敌人漏过数量、宠物有效攻击时间、控制与助威覆盖。
- 按物种与词条统计选择率和通关率，结合获取层数与星级分析，避免把相关性直接当成强弱结论。

小规模试玩先观察决策与理解，不用少量样本宣称精确平衡。基础难度的暂定目标为：完成教学后，熟悉规则的玩家通过合理布阵可稳定推进；测试者经过 2～3 局学习后，整体通关率尝试落在 40%～60%。

### 15.3 主要风险与应对

| 风险 | 表现 | 首轮应对 |
| --- | --- | --- |
| 变异只有数值差异 | 玩家不看词条，哪个面板高就选哪个 | 优先调整射程、攻速、控制与范围的实际战术影响 |
| 高星绝对优于铺场 | 所有同种都立即合成 | 检查双入口覆盖、控制合并损失与单目标过量伤害 |
| 捕捉节点压倒其他选择 | 因为缺宠，永远选择捕捉 | 比较战斗金币、奖励宠、商店价格和精英遗物收益 |
| 随机性导致无解 | 关键物种缺失或变异破坏主力 | 保留持有物种供给、默认继承、保持默认选项和基础阵容通关能力 |
| 低树心滚雪球 | 一次漏怪后无法恢复、只能等输 | 保障可达营地、前置敌人预告、保留首领后恢复 |
| 变异过于安全 | 玩家无脑选择所有新变异 | 检查负面是否真实影响当前地图与敌人；保留强度不同的适用场景 |
| 单局过长 | 波间整理与动画拖慢节奏 | 缩短出怪空档、允许跳过动画、用倍速改善重复阶段 |

## 16. V0.2 的候选改进方向

根据 V0.1 试玩结果决定优先级，不同时扩张所有系统：

1. 若单词条已经有趣，优先增加会改变攻击行为的物种专属变异，例如分裂泡泡、弹跳栗子。
2. 若路线差异不足，增加具有明确构筑倾向的捕捉地与区域生态，强化“我为什么走这条路”。
3. 若开局重复感高，加入不同的初始伙伴组合与起始遗物，保持横向差异。
4. 若变异缺少长期情感，增加命名、变异形态图鉴和远征纪念展示。
5. 只有当单词条的可读性、平衡和表现都得到验证后，再讨论第二变异槽、跨物种合成或遗传系统。

**V0.1 的核心验收：玩家能带着一支由自己选择、合成并适应变异结果的萌宠队伍，完成从摇篮树出发、沿路线探索、守住树心到抵达净土的一次完整远征。**
