# MVP 界面约定

模式：Operate。用户已确认浅色森林棋盘风格，优先可玩；本轮直接以 Cocos 代码实现。

## Direction contract

THESIS：让路线选择、近远程差异、树桩放置与基地危险可直接读懂。

OWN-WORLD：浅绿战场、深绿文字与主要按钮、橙色近战猫、蓝色远程兔；系统中文字体，图形全部程序绘制。颜色与文字共同标明状态。

STORY：玩家先选亮起的连线节点，进入战斗选择宠物、点击树桩，主动开战；胜利后沿已选分支继续，失败可重新开始。

灵露版竖屏：顶部显示灵露及收入，底部并列四个纯头像，价格和数值集中于顶部数据卡。拖动头像到空树桩松手召唤，保留点击卡片再点树桩；点场上宠物选择具体实例并查看范围与即时数据，长按 0.3 秒拖动搬迁，战斗中可实时操作；后备用弹窗选取，最多 3 列 4 行。拖动预览高亮空树桩与目标射程；松手才校验并扣款，无效或取消不扣款。底部提示当前操作，暂停明确说明产出与操作冻结。

FIRST VIEWPORT：仅竖屏，720×1280 基准。顶部标题和树心；路线在中间自下而上分岔，说明与伙伴位于底部。进入战斗后顶部是进度与灵露，顶部还包含选中数据卡，中间是左上入口至右下摇篮树的折返道路与 16 个树桩，底部是四个纯头像与开战/暂停、倍速、后备控制。长屏扩展中间区域，短屏等比留边；横屏/正方形只显示“请竖屏游玩”并冻结战斗，回竖屏保留玩家原来的手动暂停状态。

FORM：用户指定的森林棋盘与路线结构，不进行随机方向选择；seed: none (user-pinned)。签名交互是放置时展示橙/蓝攻击范围与绿/紫施法范围，战斗中对应挥击/弹道。

FINISH：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
