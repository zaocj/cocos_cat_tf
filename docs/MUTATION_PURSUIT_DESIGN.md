# 变异追求循环设计提案

日期：2026-11-10；2026-11-11 更新。六宠三形态、共 18 种已实现；按用户最新要求改为同名去重的多变异，合成保留全部旧变异，三星最多三种。下文“单变异/替换”属于原始提案，已由 GAME_DESIGN 顶部最新规则覆盖。其余五宠第三形态采用本轮 BALANCE 表，原提案全量机制重做与贡献统计尚未完成；本轮数据不表示已验证玩家平衡。

## 1. 希望玩家产生的行为

玩家先通过一次变异发现一种打法，再为它调整位置、购买伙伴、分配灵露；下一次有机会时，决定继续强化主力，还是补齐队伍短板。远征结束后，记住这只宠物和这套阵容，并想尝试另一种组合。

一次有效的变异至少应该改变一项后续决定：宠物放哪里、下次买谁、灵露先用于什么、哪种敌人需要提前防备。只让资料卡数字变大，不足以承担这个目标。

三个追求尺度：

- 短期：再得到一个同种素材，就能升星并尝试变异。
- 中期：已有核心形态，接下来寻找能补足它的伙伴或另一种变异。
- 跨局：记录实际用过的形态和通关阵容，尝试尚未完成的搭配。

## 2. 当前基础与问题

以当前源码为准：六宠、猫兔开局、随机召唤 30、驿站扩池 20、同种同星 2 合 1、三星上限、合成 50% 变异、每只最多一个变异。候选目前固定为该物种的属性卡和特性卡。新机会触发时必须二选一，三星后不再有合成机会。

主要问题：

1. 候选组合固定，重复游玩很快熟悉全部选择。
2. 缺少一条可规划的变异获得路径；玩家可能投入很多召唤成本，仍没体验到核心系统。
3. 升星和保护已有构筑可能冲突；一旦增加随机候选，强制替换会放大这种冲突。
4. 三星宠物没有调整形态的入口，核心养成较早结束。
5. 当前大部分特性卡是追加收益，属性卡也常体现为更高平均输出，阵容和站位的变化不够显著。
6. 缺少使用后的贡献反馈与跨局收录，玩家难以记住一次成功的变异。

## 3. 首版规则边界

保留：现行星级倍率、普通合成 50% 概率且无隐藏保底、单宠单变异、目标优先继承、随机召唤和驿站经济、当前三类路线节点、树心及战中操作规则。

本提案明确提出以下规则变更，须实现时同步设计、测试与存档内容版本：

| 项目 | 当前 | 提案 |
| --- | --- | --- |
| 每宠形态池 | 固定两种 | 三种，共 18 种；从三种中形成双选 |
| 已有变异的再次选择 | 固定两张，可能必须更换 | 当前形态作为一张，另一张为不同的新形态 |
| 获得途径 | 仅合成概率触发 | 保留合成；增加两次由远征检查点奖励的主动蜕变机会 |
| 三星调整 | 无入口 | 可以消耗主动蜕变机会调整，星级不变 |
| 局后记录 | 无变异收藏 | 记录实际使用的形态与通关阵容 |

主动蜕变是新的明确获得途径，不是恢复旧版 20% / 连败保底 / 催化露规则。首版也不增加新的付费货币、词条叠加、稀有度或羁绊套装。

## 4. 获得：随机惊喜与可规划机会

### 4.1 普通合成

- 仍免费升星；每次合法合成判定一次 50% 变异。
- 未触发，按照现行目标优先、其次素材的规则继承。
- 触发后，先确定升星与继承结果，再生成候选并冻结；仍必须从两张卡中选一张。
- 结果没有变异：从该物种三种形态中等概率抽两种，不重复。
- 结果已有变异：一张为“保留当前形态”，另一张从其余两种形态中等概率抽取。
- 选择当前形态也完成这次事务；不能取消、退款、换素材或重抽。
- 若双方素材形态不同，没有触发时也不能免费任选；仍保留目标优先规则，合成前显示继承预览。

三选二的首次机会中，某个指定形态出现概率为 2/3；已有形态时，某个指定替代形态出现概率为 1/2。这是条件概率，不包含 50% 合成触发判定，也不代表每局都能得到指定形态。

### 4.2 主动蜕变

- 完成第 3 站精英节点和第 6 站 BOSS 节点，各获得 1 次；全局最多获得 2 次，可以暂存。
- 依据节点成功完成发放，不要求击杀关底敌人；树心仍存活且节点完成时按现行通关规则处理，不额外惩罚 BOSS 漏过。
- 奖励不是两种新节点，不替换第 4 站全营地，也不改变第 2/8/11 站的营地/驿站布局。
- 玩家在后续战斗的准备阶段选择一只已持有的二星或三星宠物，确认后消耗 1 次并立即进入双选。
- 可选场上或后备实例；一星不能用。没有合法目标就保留机会，并说明“先合成一只二星伙伴”。
- 不花灵露、不送星级、不生成宠物、不改变原投入价或放生返还。
- 双选规则与普通变异相同；保证发生一次形态选择，不保证指定形态出现。
- 已有形态时，保留当前也消耗机会。确认前必须清楚告知；看到候选后不能撤销。
- 暂停、战斗、地图、营地、驿站、结算及其他待选事务中不能使用；不在战中新增一个强制弹窗。
- 未使用机会本局结束清空，不折算灵露、不跨局囤积。

它解决两件事：让通过早期精英的玩家能规划一次变异体验；让三星主力仍能调整。它不保证玩家能到达第 3 站，也不保证当时已经持有二星。

不在第 9 站继续发，先控制总量和弹窗频率；后续根据一局时长与实际使用数据再评估。

## 5. 形态内容：六宠各三种

以下是目标形态池。既有名称不代表沿用当前所有数值；“震荡爪、双星弹、灵铃共鸣、蔓延孢雾、雷羽连鸣”等的代价或机制调整也属于本提案的规则变更。

| 宠物 | 形态 | 明确优势 | 明确代价 | 引导的决定 |
| --- | --- | --- | --- | --- |
| 猫 | 巨力 | 高单次伤害 | 攻击更慢、容易过量伤害 | 集中照顾单体，另配清群伙伴 |
| 猫 | 震荡爪 | 周期性近距离溅射 | 常态主目标伤害降低 | 把控制点放在猫的覆盖区 |
| 猫 | 长臂 | 明显扩大攻击覆盖 | 每击伤害降低 | 覆盖弯道和多段道路，补漏 |
| 兔 | 巨力 | 高伤星弹 | 发射更慢、补漏间隔变长 | 放在可长期覆盖强敌的位置 |
| 兔 | 双星弹 | 周期性多目标弹道 | 主弹伤害降低；无第二目标不追加 | 处理分散小怪，另配单体输出 |
| 兔 | 追星 | 更广的索敌范围和更快弹道 | 伤害降低 | 在后段作为可靠补漏位 |
| 鹿 | 浓露 | 集中强化少量主力 | 光环范围缩小 | 主力集中，控制点与鹿相邻 |
| 鹿 | 灵铃 | 提高友军攻击频率 | 攻击力助威比例降低 | 支持依赖实际攻击计次的伙伴 |
| 鹿 | 广播 | 光环覆盖更广 | 助威强度明显降低 | 服务跨道路分散部署 |
| 菇 | 浓孢 | 更高单位时间范围伤害 | 施法范围缩小 | 配合藤蔓，把敌人留在小范围 |
| 菇 | 蔓延 | 第三次脉冲覆盖更大 | 常态脉冲伤害降低 | 覆盖多段道路，靠持续攻击触发扩散 |
| 菇 | 急孢 | 脉冲更频繁 | 每次脉冲伤害降低 | 降低断伤和过量伤害，持续压制回春敌人 |
| 藤蔓 | 缠生 | 单次阻挡更久 | 冷却更长 | 给高输出小区域创造停留时间 |
| 藤蔓 | 迅芽 | 更频繁地接力拦截 | 每面藤蔓寿命更短 | 沿道路分配控制覆盖 |
| 藤蔓 | 远藤 | 从更远处选取施放点 | 藤蔓寿命降低 | 支持远离道路前排的部署位 |
| 雀 | 巨力 | 连锁每段伤害提高 | 施放更慢 | 高伤连锁，另配快速补漏 |
| 雀 | 雷羽 | 每次可连锁更多目标、后跳衰减更轻 | 首目标伤害降低 | 依赖高密度敌群，配合阻挡 |
| 雀 | 远跳 | 跳跃距离明显增加 | 每跳伤害降低 | 连接分散目标，降低断链 |

三种形态应在实际关卡中各有适用场景。若总有一张任何阵容都选，就先改该卡，不通过更低出现率制造“稀有强卡”。同一物种不同形态能同时上场；优势应来自真实作用，首版没有凑齐指定形态就自动增加数值的套装奖励。

### 5.1 第一轮可直接试做的数值

下表全部是实验起点，须通过真实随机召唤经济和正常收入重跑平衡。

| 形态 | 建议起点 |
| --- | --- |
| 巨力猫/兔/雀 | 沿用伤害 ×2、间隔 ×1.5；其他基础机制保留 |
| 震荡猫 | 常态伤害 ×0.85；每第 3 击对主目标外最多 3 个敌人造成该次有效伤害的 60%，范围 90；按距离、ID 稳定选取 |
| 长臂猫 | 射程 ×1.6、伤害 ×0.75；保持原攻击间隔 |
| 双星兔 | 主弹伤害 ×0.9；每第 3 发向另一存活敌人追加主弹伤害 70% 的星弹；没有第二目标则不追加 |
| 追星兔 | 射程 ×1.35、弹速 ×1.5、伤害 ×0.8；没有额外弹道 |
| 浓露鹿 | 沿用助威比例 ×1.6、范围 ×0.7 |
| 灵铃鹿 | 助威比例 ×0.75；范围内其他宠物攻速 +20%，同类不叠加 |
| 广播鹿 | 范围 ×1.4、助威比例 ×0.6；不附加攻速 |
| 浓孢菇 | 每次脉冲伤害 ×1.6、范围 ×0.75；间隔不变 |
| 蔓延菇 | 伤害 ×0.9；每第 3 次脉冲范围 ×1.6，其余保持基础范围 |
| 急孢菇 | 脉冲间隔 ×0.6、每次伤害 ×0.65；范围不变 |
| 缠生藤蔓 | 沿用寿命 ×2、间隔 ×1.5 |
| 迅芽藤蔓 | 沿用寿命 ×0.75、间隔 ×0.65 |
| 远藤 | 范围 ×1.5、寿命 ×0.6；间隔不变 |
| 雷羽雀 | 每次最多 5 目标、逐跳保留 80%、基础伤害 ×0.8；取消原每第三击额外目标机制 |
| 远跳雀 | 跳距 ×1.6、伤害 ×0.85；保持基础 3 目标和 70% 衰减 |

只有真实攻击/有效脉冲才增加攻击计次，空等不能蓄第三击。冷却与旧弹道、旧藤蔓继续遵守快照规则；蜕变不能重置冷却、刷新已发射效果或制造免费攻击。

当前护甲是比例减伤。同样总直击伤害下，高单次伤害没有额外穿甲优势，不能把巨力文案写成“克制护甲”。菇依旧走孢子穿甲规则；急孢对回春的价值取决于真实覆盖和断伤，不能宣传为无条件克制。

## 6. 三条可被玩家记住的构筑

| 构筑 | 关键形态 | 后续追求 | 需要承担的短板 |
| --- | --- | --- | --- |
| 林间伏击 | 震荡猫 + 缠生藤蔓 | 把阻挡点落进溅射覆盖，补浓露鹿或远程补漏 | 小覆盖区，控制空窗与漏网快怪 |
| 孢雾温室 | 浓孢菇 + 藤蔓，鹿按站位选择 | 购买菇和控制伙伴，安排持续覆盖区 | 区域外没有伤害，精英突破后需要后段火力 |
| 雷鸣接力 | 雷羽雀 + 迅芽藤蔓 | 利用敌群密度和控制接力；若经常断链可转远跳 | 独立 BOSS、稀疏目标，需要猫兔补单体 |

这三条是介绍与验证用例，不是预设职业，不改变召唤权重，不要求玩家集齐特定名单才能得到系统奖励。

灵铃鹿对猫/兔/菇的计次特性提供更多实际触发，对新版雷羽雀只提供正常攻击加速。文案不能把不存在的每第三击联动继续写进推荐。

## 7. 一局中的体验节奏

1. 第 1～3 站：用猫兔学习召唤、合成；自然触发的形态可以成为方向，但早期无变异仍应具有可玩性。
2. 第 3 站完成：明确获得一次主动蜕变机会。下一次准备时给一次非强制入口提示，不马上叠一个选择弹窗。
3. 第 4～6 站：围绕已有形态调整部署；未进入早期驿站也能用猫兔继续成长。不能让辅助宠成为固定通关门票。
4. 第 6 站完成：第二次机会给主力调整或辅助成形。玩家可以留到第 8 站驿站购入新种类、召唤并合到二星之后再用。
5. 第 7～12 站：验证阵容，补缺口；三星主力的形态仍可借保留机会调整，但没有无限重抽。
6. 结算：展示被使用的形态、阵容及相应贡献；跨局收藏给出下一次尝试的目标。

示例只是可行叙事：早期随机获得震荡猫，玩家在驿站解锁藤蔓并通过正常召唤取得实例，把藤蔓阻挡点安排在猫范围内；第 6 站后的机会可用于二星藤蔓尝试缠生，也可以留给三星猫。必须允许没抽到藤蔓、没有对应形态的分支，不把这段示例当作保证出现的教程脚本。

## 8. 让选择看得懂、用起来看得见

- 合成前：展示升星结果、继承形态、50% 触发概率；不预抽候选。
- 双选卡：第一行“改变什么”，第二行“付出什么”，第三行用当前星级展示实际数值；已有形态卡标“保留”，不标为免费。
- 原型卡示例，二星猫未计鹿增益：巨力 91.2 伤害 / 0.975 秒 / 94 范围；震荡常态 38.76 / 0.65 秒 / 94 范围，并注明第三击范围效果；长臂 34.2 / 0.65 秒 / 150.4 范围。
- 优先展示实际伤害、间隔、范围和条件，不用一个总战力箭头替代取舍。
- 概率、池与主动机会在确认前可查；候选出现后存档固定，转屏/后台保留。
- 宠物有形态轮廓、局部装饰和攻击特效差异，颜色之外还要有可辨认标记。
- 点击宠物可查看形态；沿用按需底部资料浮层，不恢复常驻大资料卡，不增加常驻战斗弹窗。
- 主动蜕变次数在准备阶段的培养入口显示；合成和蜕变使用同一双选面板，避免重复的系统学习成本。

只用事实展示贡献：输出统计有效伤害、溅射/连锁额外目标；藤蔓统计实际阻挡的敌人秒数，同一敌人重叠控制不能重复计；鹿可先展示有效助威覆盖时间，不在没有反事实计算时虚构“额外造成多少伤害”。

## 9. 跨局追求

- 形态图鉴固定 18 个位置，第一次采用并完成一场战斗后收录；只看见候选不算使用收录。
- 若选择发生在战中，之后完成当前战斗也计入；失败局中之前已经使用成功的形态仍保留。
- 图鉴可查看未收录形态的基本规则，玩家能提前形成目标；不把重要机制藏进问号。
- 历史记录区分“使用过”和“携带该形态通关过”；后者是更长的追求。
- 结算保存实际阵容、路线和形态，允许收藏本次阵容作为下次参考；收藏不改变抽取概率或初始宠物。
- 首版收藏只给展示和成就，不给永久攻击力，不要求收集完成才能正常通关。

## 10. 验证与退出条件

玩法原型先只做三种猫形态、候选保护和两次主动机会，利用现有藤蔓/鹿测试站位改变。验证成立后再扩到全六宠，避免同时投入 18 套表现却发现选择依旧固定。

首轮观察至少覆盖三个问题：

1. 玩家看完卡能否说出“我拿到了什么、失去了什么、准备怎么用”？
2. 采用后是否出现一次可观察的后续决策变化，而不只是继续点击召唤？
3. 一局结束后能否记得核心宠物的形态，并提出下一局想试的搭配？

用 8～12 位未参与开发的玩家作探索性试玩，不把这批人数当作通关率或留存率的统计证明。记录首次变异站数、主动机会获得/使用/放弃时机、候选与选择、选择后的购买/移位、失败原因和再开一局意愿。玩家可能本来就要搬迁，因果仍需结合追问。

数值验证：使用真实两宠开局、正常收入与随机召唤，不预装形态或注入灵露。至少比较多种策略、不同候选策略及机会使用时机；重跑 0% 自然变异压力测试时，应明确主动蜕变是否开启，不能与旧的完全无变异条件混淆。原有 80/100 固定策略阈值不能直接充当新设计的体验验收。

重点边界：单体/密群/稀疏敌群、实际路径覆盖、长时间藤蔓接力、助威不叠加、过量伤害、无第二目标、三星调整、旧弹道与墙快照、奖励只发一次、重复点击、暂停冻结和整局恢复一致。模拟正确之后仍需编辑器、独立构建和真机操作验证。

## 11. 工程落点与交付次序

1. `PetGrowth` 配置物种形态集合、稳定 ID、倍率和卡片；领域层校验物种与形态对应，不能继续只凭全局 power/resonance 字符串判断合法。
2. `MvpSession` 处理候选采样、继承保护、检查点去重奖励和主动蜕变事务；有效形态统一查询，表现层不计算规则。
3. 普通合成对独立变异 PRNG 仍只推进一次；可从该次随机字的不同区间或局部派生结果形成触发与候选，不能让 UI 预览额外抽样。主动蜕变每次合法确认独立推进一次，失败不推进。具体采样实现必须验证分布及分流。
4. 快照增加剩余机会、已发奖励检查点、事务来源与真实候选；命令确认时先原子扣次数并固定候选，选择阶段不能取消。保存失败沿用暂停与显式重试流程。
5. 档案增加已使用形态和通关记录，并定义去重更新。升级内容版本；兼容旧档须另做显式迁移，不能静默删除旧档。
6. 表现增加准备入口、双选比较、形态标记与结算展示；新增资源经编辑器导入，维护 meta，不手工改场景结构。
7. 全六宠内容与局后图鉴分批完成；本提案不把工程设计视为已实现功能。

推荐首个可评审切片：三形态猫 + 合成候选保护 + 第 3/6 站主动蜕变 + 简单局后形态记录。遗物、额外节点、第四种形态、永久成长留待这个切片验证后决定。
